# NeoTACZ 26.2 Port

这是 `SHMBerBerder` 维护的 TACZ 非官方 NeoForge/Minecraft 26.2 移植仓库。

## 项目定位

- 目标版本：Minecraft 26.2 / NeoForge 26.2。
- 这个仓库用于个人移植、适配和测试，不是 TACZ 官方发布仓库。
- 历史的 `1.20.1` 分支名不再代表本仓库目标；当前移植分支是 `26.2`。

## 非官方声明

本项目与 TACZ 官方版无关，不由原 TACZ 团队维护，也不代表官方更新路线、发布节奏或技术支持。
官方版本、反馈入口和文档请以 TACZ 官方渠道为准。

## 移植范围

- 将 TACZ 代码和资源适配到 NeoForge/Minecraft 26.2。
- 保留原有枪械玩法基础，按 26.2 运行时调整构建、API、客户端渲染和兼容层。
- 本仓库产物仅代表此移植工程，不应被当作官方 TACZ 版本。
